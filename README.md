# Placewick

Placewick is a student-focused internship and placement platform designed to help Nigerian students discover relevant opportunities and connect directly with companies.

The goal is to make finding internships easier, safer, and more personalized for students.

## ✨ Features

- 🔐 **Verified Opportunities**  
  Helps students discover internship opportunities from verified companies.

- 🎯 **Smart Matching**  
  Matches students with opportunities based on their profile, interests, and skills.

- 💬 **Direct Communication**  
  Allows students to connect and communicate directly with companies.

- 📱 **Responsive Design**  
  Designed to work across desktop, tablet, and mobile devices.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Lucide Icons

## 🎨 Design

Placewick uses a clean, modern interface focused on making internship discovery simple and approachable.

The design emphasizes:

- Clear navigation
- Simple user flows
- Accessible layouts
- Responsive components
- Student-friendly experiences
